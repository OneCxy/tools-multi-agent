# 月牙洼磨损：参数调整边界

## 结论
针对月牙洼磨损调整参数时一次只改变一个主要变量，并保证不超出厂商对牌号、槽型和刀体的允许范围。

## 适用条件
适用于车削、铣削、钻削相关判断；具体产品需核对厂商现行目录。

## 说明
安全检查 → 装夹与刀座 → 刀片磨损 → 切屑状态 → 参数与冷却 → 材质和槽型。
