# 坡走铣与螺旋插补：关键输入

## 结论
开始坡走铣与螺旋插补选型前，应确认刀具允许的坡走角、孔径范围和轴向负载。

## 适用条件
适用于坡走铣与螺旋插补相关判断；具体产品需核对厂商现行目录。

## 说明
该卡片提供通用判断顺序，不替代具体厂商的产品规格和切削参数表。
