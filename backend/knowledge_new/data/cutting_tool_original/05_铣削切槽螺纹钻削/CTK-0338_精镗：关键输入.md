# 精镗：关键输入

## 结论
开始精镗选型前，应确认孔公差、表面粗糙度、调整分辨率和热稳定性。

## 适用条件
适用于精镗相关判断；具体产品需核对厂商现行目录。

## 说明
该卡片提供通用判断顺序，不替代具体厂商的产品规格和切削参数表。
