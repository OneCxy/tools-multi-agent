# 槽铣：Agent追问

## 结论
当用户询问槽铣但信息不足时，应围绕以下内容追问：确认满槽或部分吃刀、排屑空间和刀具过中心能力。

## 适用条件
适用于槽铣相关判断；具体产品需核对厂商现行目录。

## 说明
该卡片提供通用判断顺序，不替代具体厂商的产品规格和切削参数表。
