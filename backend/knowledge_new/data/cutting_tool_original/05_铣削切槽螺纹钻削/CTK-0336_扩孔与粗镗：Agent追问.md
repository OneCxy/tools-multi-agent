# 扩孔与粗镗：Agent追问

## 结论
当用户询问扩孔与粗镗但信息不足时，应围绕以下内容追问：确认原孔状态、余量、同轴度和刀具悬伸。

## 适用条件
适用于扩孔与粗镗相关判断；具体产品需核对厂商现行目录。

## 说明
该卡片提供通用判断顺序，不替代具体厂商的产品规格和切削参数表。
