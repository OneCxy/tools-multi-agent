# 车削加工时间计算示例1

## 结论
公式：`tm = L / (fn × n)`。变量定义：tm为min，L为mm，fn为mm/rev，n为r/min。示例1：输入1=100、输入2=0.17、输入3=850，计算结果约为 **0.692**。

## 适用条件
适用于车削、铣削、钻削相关判断；具体产品需核对厂商现行目录。

## 说明
`tm = L / (fn × n)`

tm为min，L为mm，fn为mm/rev，n为r/min。
