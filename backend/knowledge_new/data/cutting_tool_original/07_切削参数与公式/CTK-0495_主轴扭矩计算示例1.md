# 主轴扭矩计算示例1

## 结论
公式：`T = 9550 × P / n`。变量定义：T为N·m，P为kW，n为r/min。示例1：输入1=6、输入2=600，计算结果约为 **95.5**。

## 适用条件
适用于车削、铣削、钻削相关判断；具体产品需核对厂商现行目录。

## 说明
`T = 9550 × P / n`

T为N·m，P为kW，n为r/min。
