# 车削加工时间计算示例3

## 结论
公式：`tm = L / (fn × n)`。变量定义：tm为min，L为mm，fn为mm/rev，n为r/min。示例3：输入1=140、输入2=0.21、输入3=950，计算结果约为 **0.702**。

## 适用条件
适用于车削、铣削、钻削相关判断；具体产品需核对厂商现行目录。

## 说明
`tm = L / (fn × n)`

tm为min，L为mm，fn为mm/rev，n为r/min。
