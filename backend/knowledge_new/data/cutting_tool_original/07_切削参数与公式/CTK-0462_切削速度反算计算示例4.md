# 切削速度反算计算示例4

## 结论
公式：`vc = π × D × n / 1000`。变量定义：vc为m/min，D为mm，n为r/min。示例4：输入1=60、输入2=1300，计算结果约为 **245**。

## 适用条件
适用于车削、铣削、钻削相关判断；具体产品需核对厂商现行目录。

## 说明
`vc = π × D × n / 1000`

vc为m/min，D为mm，n为r/min。
