# 86°菱形刀片的强度特点

## 结论
刀尖较强，但轮廓可达性受限

## 适用条件
适用于车削相关判断；具体产品需核对厂商现行目录。

## 说明
一般而言，刀尖夹角越大，刃口支承越充分；夹角越小，可达性越好但刀尖更敏感。

还要结合正负前角、刀片厚度、刀尖半径和夹紧方式。
