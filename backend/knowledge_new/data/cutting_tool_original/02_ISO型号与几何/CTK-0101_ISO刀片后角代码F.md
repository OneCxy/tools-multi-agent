# ISO刀片后角代码F

## 结论
代码F对应名义后角25°。

## 适用条件
适用于车削、镗削相关判断；具体产品需核对厂商现行目录。

## 说明
名义后角不等于实际工作后角；实际角度还受到刀座和安装姿态影响。后角增大通常减少摩擦，但也会减小刀片楔角。
