# ISO K组铸铁：问答边界

## 结论
用户只说加工铸铁时，Agent应继续询问区分灰铸铁、球墨铸铁、蠕墨铸铁和ADI，不能立即给出唯一切削参数。

## 适用条件
适用于车削、铣削、钻削相关判断；具体产品需核对厂商现行目录。

## 说明
参数引用必须带厂商、刀片牌号、槽型和适用工况；不同厂商参数不要直接求平均。
