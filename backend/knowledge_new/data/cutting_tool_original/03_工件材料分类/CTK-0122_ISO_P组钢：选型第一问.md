# ISO P组钢：选型第一问

## 结论
处理ISO P组时，第一步不是直接报牌号，而是依据含碳量、合金程度、硬度和热处理状态细分。

## 适用条件
适用于车削、铣削、钻削相关判断；具体产品需核对厂商现行目录。

## 说明
参数引用必须带厂商、刀片牌号、槽型和适用工况；不同厂商参数不要直接求平均。
