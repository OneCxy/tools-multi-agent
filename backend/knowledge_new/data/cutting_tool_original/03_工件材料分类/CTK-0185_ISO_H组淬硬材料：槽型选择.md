# ISO H组淬硬材料：槽型选择

## 结论
ISO H组选槽型时，应让有效进给和切深落入槽型断屑范围，并结合硬度高，对刃口质量、刚性和稳定性要求高判断刃口锋利度。

## 适用条件
适用于车削、铣削、钻削相关判断；具体产品需核对厂商现行目录。

## 说明
参数引用必须带厂商、刀片牌号、槽型和适用工况；不同厂商参数不要直接求平均。
