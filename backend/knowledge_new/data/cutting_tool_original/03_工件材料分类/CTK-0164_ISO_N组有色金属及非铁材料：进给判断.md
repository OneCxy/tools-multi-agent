# ISO N组有色金属及非铁材料：进给判断

## 结论
ISO N组进给量既要满足断屑槽有效区，也要受刀尖半径、表面质量和系统刚性约束。

## 适用条件
适用于车削、铣削、钻削相关判断；具体产品需核对厂商现行目录。

## 说明
参数引用必须带厂商、刀片牌号、槽型和适用工况；不同厂商参数不要直接求平均。
