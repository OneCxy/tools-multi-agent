# ISO S组高温合金和钛合金：参数记录字段

## 结论
记录ISO S组参数时至少保留具体材料、硬度、牌号、槽型、加工阶段、切削状态和来源版本。

## 适用条件
适用于车削、铣削、钻削相关判断；具体产品需核对厂商现行目录。

## 说明
参数引用必须带厂商、刀片牌号、槽型和适用工况；不同厂商参数不要直接求平均。
