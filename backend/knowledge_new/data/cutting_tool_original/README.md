# 可转位数控刀具通用知识库（700条精简版）

本库包含700份中文Markdown知识卡。每份采用“结论—适用条件—说明—来源”格式，适用于RAG原型。

## 使用边界

- 通用规则不能替代具体厂商的牌号、槽型和现行参数表。
- Tungaloy材质应用等级来自公开目录，用于牌号识别，不表示跨品牌等效。
- 具体切削参数必须同时关联材料、硬度、工序、牌号、槽型和工况。
- 所有参数类内容上线前仍需刀具技术人员抽样复核。
