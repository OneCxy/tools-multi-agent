# 车削加工时间计算

## 结论
tm = L / (fn × n)。

## 适用条件
恒定转速和每转进给量下的单次车削行程；不含换刀等辅助时间。

## 说明
tm：加工时间，min；L：本次计算的进给行程长度，mm；fn：每转进给量，mm/rev；n：转速，r/min。

已知：L = 100 mm，fn = 0.17 mm/rev，n = 850 r/min。
结果：tm ≈ 0.692 min。

示例数值用于说明计算方法，不是推荐切削参数；使用前核对机床能力与刀具工况。
