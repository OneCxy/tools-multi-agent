# 车削进给速度计算

## 结论
vf = fn × n。

## 适用条件
车削；每转进给量与转速对应同一加工工况。

## 说明
vf：进给速度，mm/min；fn：每转进给量，mm/rev；n：转速，r/min。

已知：fn = 0.12 mm/rev，n = 900 r/min。
结果：vf ≈ 108 mm/min。

示例数值用于说明计算方法，不是推荐切削参数；使用前核对机床能力与刀具工况。
