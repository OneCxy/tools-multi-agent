# 核对进给速度

## 结论
由每转或每齿进给换算，并确认数控系统使用的进给模式。

## 适用条件
适用于参数推荐、试切记录和故障复盘。

## 说明
建议把检查结果作为结构化字段保存，并与对应工件、刀具、工序和试切批次关联。
