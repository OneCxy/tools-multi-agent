# ISO N有色材料切槽切断如何初选刀片

## 结论
先按材料组筛选牌号，再按切槽切断负载选择槽型和刃口强度。

## 适用条件
适用于ISO N有色材料的切槽切断初步方案，不替代现场试切。

## 说明
应确认合金成分、含硅量、黏附和刃口锋利度；确认刀片宽度、悬伸、中心高和排屑。参数从对应厂商范围的保守端开始。
