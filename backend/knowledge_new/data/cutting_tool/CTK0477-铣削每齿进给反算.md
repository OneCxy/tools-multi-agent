# 铣削每齿进给反算

## 结论
fz = vf / (z × n)。

## 适用条件
铣削；有效齿数与转速均须大于零。

## 说明
fz：每齿进给量，mm/tooth；vf：工作台进给速度，mm/min；z：有效齿数；n：转速，r/min。

已知：vf = 700 mm/min，z = 5，n = 1300 r/min。
结果：fz ≈ 0.1077 mm/tooth。

示例数值用于说明计算方法，不是推荐切削参数；使用前核对机床能力与刀具工况。
