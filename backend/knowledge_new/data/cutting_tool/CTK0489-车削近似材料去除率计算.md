# 车削近似材料去除率计算

## 结论
Q ≈ ap × fn × vc。

## 适用条件
车削的近似材料去除率估算；按下列单位代入。

## 说明
Q：材料去除率，cm³/min；ap：切深，mm；fn：每转进给量，mm/rev；vc：切削速度，m/min。

已知：ap = 1.25 mm，fn = 0.17 mm/rev，vc = 160 m/min。
结果：Q ≈ 34 cm³/min。

示例数值用于说明计算方法，不是推荐切削参数；使用前核对机床能力与刀具工况。
