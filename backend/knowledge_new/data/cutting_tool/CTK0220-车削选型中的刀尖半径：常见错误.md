# 车削选型中的刀尖半径：常见错误

## 结论
常见错误是跳过“刀尖半径”直接套用参数。这样可能导致断屑、寿命、表面质量或安全问题。

## 适用条件
适用于车削、镗削相关判断；具体产品需核对厂商现行目录。

## 说明
结合进给、切深、表面质量和刚性选择；半径过大可能诱发振动，过小可能限制进给和强度。
