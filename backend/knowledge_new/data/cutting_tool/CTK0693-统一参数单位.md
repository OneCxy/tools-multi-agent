# 统一参数单位

## 结论
明确m/min、mm/rev、mm/tooth、r/min和mm/min，禁止混用。

## 适用条件
适用于参数推荐、试切记录和故障复盘。

## 说明
建议把检查结果作为结构化字段保存，并与对应工件、刀具、工序和试切批次关联。
