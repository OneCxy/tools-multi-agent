# 车削切削速度反算

## 结论
vc = π × D × n / 1000。

## 适用条件
车削；D为当前加工处的工件直径。

## 说明
vc：切削速度，m/min；D：工件直径，mm；n：转速，r/min。

已知：D = 45 mm，n = 1000 r/min。
结果：vc ≈ 141.3717 m/min。

示例数值用于说明计算方法，不是推荐切削参数；使用前核对机床能力与刀具工况。
