# 车削转速计算

## 结论
n = 1000 × vc / (π × D)。

## 适用条件
车削；D为当前加工处的工件直径。

## 说明
n：转速，r/min；vc：切削速度，m/min；D：工件直径，mm。

已知：vc = 190 m/min，D = 55 mm。
结果：n ≈ 1099.616 r/min。

示例数值用于说明计算方法，不是推荐切削参数；使用前核对机床能力与刀具工况。
