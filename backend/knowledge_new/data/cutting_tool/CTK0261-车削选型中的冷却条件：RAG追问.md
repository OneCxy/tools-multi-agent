# 车削选型中的冷却条件：RAG追问

## 结论
如果用户没有说明冷却条件，应追问相关信息；无法获得时只提供条件化建议并明确不确定性。

## 适用条件
适用于车削、镗削相关判断；具体产品需核对厂商现行目录。

## 说明
确认干式、湿式、内冷、压力和供液稳定性；冷却既影响温度也影响排屑和热冲击。
