# ISO K铸铁精车参数如何调整

## 结论
一次只调整一个主要参数，并记录切屑、磨损、尺寸和表面变化。

## 适用条件
适用于已确定刀片牌号和槽型后的ISO K铸铁精车试切。

## 说明
先确认速度、进给和切深均在牌号及槽型允许范围内；优先表面质量、尺寸稳定性和低切削力。若出现崩刃或异常振动，应先检查装夹而不是继续加参数。
