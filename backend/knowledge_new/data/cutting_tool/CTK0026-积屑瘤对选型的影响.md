# 积屑瘤对选型的影响

## 结论
常损害表面质量并改变刃口几何；应从速度、锋利槽型和冷却润滑条件排查。

## 说明
工件材料、加工方式、机床与装夹刚性、冷却条件，以及对应厂商的牌号和槽型说明。
